## Описание

Программа реализует бинарное дерево и бинарное дерево поиска (BST). Работа состоит из трёх частей:

1. Обходы бинарного дерева: pre-order, in-order, post-order и level-order. Подсчёт листьев, узлов и высоты.
2. Вставка, поиск и удаление элементов BST. Поиск k-го наименьшего элемента.
3. Создание BST из 20 случайных уникальных чисел, вывод отсортированной последовательности, поиск минимума и максимума, вычисление высоты и удаление ключа, введённого пользователем.

## Реализованные возможности

- Четыре способа обхода дерева.
- Подсчёт листьев и узлов, вычисление высоты.
- Удаление листа, узла с одним потомком и узла с двумя потомками.
- Обработка пустого дерева, повторяющихся ключей и некорректного k.
- Визуализация дерева в консоли до и после удаления.
- Управление памятью с помощью std::unique_ptr.
- Анализ алгоритмической сложности операций.

## Среда разработки

- Язык программирования: C++17
- IDE: Microsoft Visual Studio

## Запуск

Откройте файл `Lab9_Variant2_Year2.cpp` в проекте C++ Console App, соберите программу и запустите её. В демонстрационной части введите ключ для удаления из дерева.

## Результат

При контрольном запуске успешно пройдены 33 теста. После удаления ключа 67 корнем дерева стал ключ 75, а количество узлов уменьшилось с 20 до 19. Свойство BST сохранено.
